# Damage-claim verifier

My entry for HackerRank Orchestrate, June 2026 (24 hours; finished #206, top 11.6%).

Each claim comes with a chat transcript, one or more photos, the user's claim history and the minimum evidence required for cars, laptops and packages. The system decides whether the photos support the claim, contradict it, or aren't enough to tell. It uses Gemini vision to read the images and plain Python for the evidence rules and the history checks.

The solution and how to run it are in [`code/README.md`](code/README.md). The evaluation results are in [`code/evaluation/evaluation_report.md`](code/evaluation/evaluation_report.md).
